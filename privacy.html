JTV Archive Backup 개인정보처리방침

이 정책은 JTV Archive Backup의 개인용 Google Drive 백업 연결과 이 공개 안내 사이트에 적용됩니다.

접근하는 정보

사용자가 승인한 Google Drive 파일·폴더의 이름, 식별자, 경로, 크기, 수정 시각, 체크섬 등 메타데이터와 백업·복원·검증에 필요한 파일 내용에 접근할 수 있습니다. OAuth 권한 자체에는 파일 보기·수정·생성·삭제가 포함됩니다. 이 연결은 Gmail이나 YouTube 접근 권한을 요청하지 않습니다.

이용 목적

Google Drive 데이터는 소유자가 요청한 아카이브 백업·복원·정리·정상 저장 검증에 사용합니다. 데이터를 판매하거나 광고 타기팅에 이용하지 않으며, 범용 AI 모델 개발·학습 목적으로 이용하지 않습니다.

별도의 분석 작업에서 외부 AI·음성 처리 서비스 등을 사용하는 경우에는 소유자가 승인한 작업 범위와 서비스에 따라 필요한 자료만 별도로 처리합니다. 백업용 OAuth 권한을 부여했다는 사실만으로 그러한 별도 작업을 승인한 것으로 간주하지 않습니다.

저장과 공유

아카이브와 작업 자료는 소유자가 관리하는 Google Drive, PC 또는 VPS에 저장될 수 있습니다. 인증정보는 자동화 환경에서 접근 권한을 제한하여 관리하고, 공개 저장소나 이 홈페이지에 게시하지 않습니다. Google 및 소유자가 선택한 저장·호스팅 서비스는 각 서비스 정책에 따라 데이터를 처리합니다.

공개 GitHub 저장소에는 앱 안내와 정책 문서만 올립니다. 이 안내 페이지는 자체 로그인 양식, 광고, 추가 추적 스크립트를 포함하지 않습니다. GitHub Pages의 일반적인 호스팅 처리에는 GitHub 개인정보처리방침이 적용됩니다.

보존과 삭제

백업 보존 기간과 삭제는 소유자가 관리합니다. 접근 권한을 철회하더라도 이미 만들어진 백업 사본이 자동으로 삭제되지는 않습니다. 필요하면 Google Drive, PC, VPS에 남은 사본과 인증 설정을 각각 확인하여 삭제해야 합니다.

접근 권한 철회

소유자는 Google 계정의 외부 앱 연결 관리에서 이 앱의 접근 권한을 철회할 수 있습니다. 철회 후에는 해당 승인에 따른 추가 Google Drive 접근을 계속할 수 없습니다.

Google API 데이터 정책

Google API를 통해 받은 정보의 이용과 다른 앱으로의 전송은 Google API Services User Data Policy와 Limited Use 요구사항을 따릅니다.

문의와 변경

문의는 Google OAuth 동의 화면에 표시된 사용자 지원 이메일로 접수합니다. 처리 방식이 변경되면 이 정책도 실제 운영 방식에 맞게 수정합니다.
